# potential-admin

A repository setup for GitHub Copilot integration.

## GitHub Copilot Setup

This repository is configured to work with GitHub Copilot. See [COPILOT_SETUP.md](COPILOT_SETUP.md) for detailed instructions on how to enable GitHub Copilot access for this repository.

## Quick Start

1. Ensure you have GitHub Copilot access (individual or organization subscription)
2. Enable Copilot for this repository through GitHub settings
3. Install GitHub Copilot extension in your IDE
4. Start coding with AI assistance!
